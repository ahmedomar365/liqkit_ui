# liqkit_ui_tokens

Typed iOS 26 design tokens for [`liqkit_ui`](https://pub.dev/packages/liqkit_ui).

The canonical surface is in `LiqCanonicalColors` and `LiqCanonicalTypography`,
generated by pure Dart from `packages/liqkit_ui_design_data/manifests/canonical_tokens.json`
(captured from liqkit's Figma `variable-defs.json` files across all 37
categories). Do not edit `lib/src/*.dart` by hand.

To regenerate:

```sh
dart run tooling/gen/capture_canonical_tokens.dart
dart run tooling/gen/generate_canonical_dart.dart
```
