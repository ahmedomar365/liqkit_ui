A social-feed app structured like a typical photo-sharing product:
stories bar, scrollable feed with rich post cards, profile grid,
notifications, message threads, and a create-post sheet.

## What it shows

- **Feed** with `LiqCard`-shaped post cards, image header, author row
  with `LiqAvatar`, `RichText` caption with `@mentions`,
  like/comment/share row of `LiqIconButton`s
- **Stories bar** — horizontal `ListView` of avatar rings using
  `LiqAvatar` + gradient ring
- **Profile screen** with sliver app bar, tab-strip via
  `LiqSegmentedControl`, photo grid via `SliverGrid`
- **Notifications** with `Text.rich` cascading colored read-state
  styles
- **Create post** as a modal `LiqSheet` with image picker, caption
  field, location chip, post button
- **Messages** as a list of `LiqListRow`s opening into a threaded
  chat

## Components emphasized

`LiqCard` · `LiqAvatar` · `LiqIconButton` · `LiqSegmentedControl` ·
`LiqChip` · `LiqContextMenu` · `LiqSheet` · `LiqTextField` ·
`LiqFloatingActionButton` · `LiqBadge` · `LiqList`
