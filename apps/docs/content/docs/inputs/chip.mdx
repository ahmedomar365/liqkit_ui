`LiqChip` is an interactive tag pill. It can render in a selected state
(filled blue), accept taps via `onPressed`, and carry an inline delete
affordance via `onDeleted`. Use it for tag inputs, filter pills, and
multi-select facets. For read-only counters or status indicators, reach
for `LiqBadge` instead.

## Single

A free-standing chip. Mark one as `selected` to flip its fill to the
iOS system blue.

## Group

`LiqChipGroup` lays a list of chips out in a wrap with iOS-correct
spacing. Pair it with `selected` + `onPressed` to build a multi-select
facet.

## Dismissible

Pass `onDeleted` to render an inline "x" button. Tapping the affordance
fires `onDeleted` only — it never bubbles to `onPressed`.
