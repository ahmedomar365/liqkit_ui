liqkit_ui ships two colour-picker widgets. `LiqColorPickerButton` is a
circular button with a conic-gradient hue ring and an inset swatch.
`LiqColorGrid` is a scrollable grid of solid colour swatches.

The 36pt button — the default size for prominent colour controls.
