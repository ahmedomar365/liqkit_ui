`LiqStepper` is the iOS 26 stepper control. The − and + buttons
automatically dim when the value reaches `min` or `max`.

## Default

An active stepper with value 3 — both buttons are tappable.

## Disabled

Pass `onChanged: null` to make the entire control non-interactive. Both
buttons render in the disabled colour.
