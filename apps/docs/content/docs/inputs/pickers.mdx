The picker family gives you a single-column tap-to-open sheet, multi-column
wheel pickers, number / measurement steppers, inline wheel-style date and
time pickers (5 modes), trigger-button list rows that open a wheel sheet,
date-range coupling, and four timer-picker modes for countdowns.

Every variant below is the same widget the showcase app on the App Store
uses — sourced from `package:liqkit_ui/examples.dart` so the docs and the
mobile app stay in sync.

## Inline Calendar

`LiqDatePicker` renders an iOS 26 inline month calendar with prev/next
arrows, a weekday row, and a 7-column day grid. Today's date gets a blue
ring; the selected day gets a tinted fill.
