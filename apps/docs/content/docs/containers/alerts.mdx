`LiqAlert` is the iOS 26 alert dialog — a 300pt translucent surface with
a bold title, optional description, and one or more action buttons.

## Stacked

Actions rendered in a vertical stack (one per row). The default layout for
alerts with two or more actions.

<LiqPreview component="alert" variant="stacked" />

<CodeSnippet snippet={alertStackedSnippet} />

## Side by Side

Two equal-width actions placed side-by-side. Use
`layout: LiqAlertActionLayout.sideBySide` with exactly two actions.

<LiqPreview component="alert" variant="side-by-side" />

<CodeSnippet snippet={alertSideBySideSnippet} />

## Destructive

An action rendered with `LiqAlertActionStyle.destructive` shows the label
in system red, signalling an irreversible operation.
