`LiqMenu` renders a 238pt translucent rounded panel of `LiqMenuItem` rows.
Sections can be delineated with `LiqMenuSectionTitle` and `LiqMenuSeparator`.

## Default

A plain list of `LiqMenuItem` rows. The last item demonstrates
`LiqMenuItemStyle.destructive`.
