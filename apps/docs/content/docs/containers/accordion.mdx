`LiqAccordion` is a vertically stacked set of expandable panels. Tap a
header to reveal its content. Single mode keeps only one panel open;
multiple mode allows several at once.

## Default

Two-panel accordion in single mode. None are expanded initially.

## Single

Common FAQ pattern — only one panel can be open at a time. The first
item is expanded on first paint.

## Multiple

Pass `type: LiqAccordionType.multiple` to allow several panels open
