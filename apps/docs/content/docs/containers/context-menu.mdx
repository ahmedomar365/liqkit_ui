`LiqContextMenu` composes a `LiqContextMenuPreview` tile and a `LiqMenu`
panel. The `LiqContextMenuArrangement` enum controls whether the menu sits
below or beside the preview, and which edge it aligns to.

## Below Leading

Menu below the preview, aligned to the leading (left) edge. This is the
default arrangement.

Menu below the preview, aligned to the trailing (right) edge.

where vertical space is limited.
