`LiqMaterialChip` renders an iOS 26 frosted-glass surface. It uses
`BackdropFilter` to blur whatever sits behind it, then layers the
brightness-appropriate tint and highlight border on top — matching the
CSS `backdrop-filter` spec from Apple's HIG exactly.

Five thickness presets (`ultraThin` → `chrome`) control overlay alpha
and blur radius; the examples below use the default `regular` preset.
