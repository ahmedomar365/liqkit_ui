`liqkit_ui` exposes the full iOS 26 text-style system through
`LiqTypeColumn`. Each column renders all eleven semantic roles
(`largeTitle` → `caption2`) at the requested Dynamic Type scale, letting
you preview exactly how your typography responds to the user's size
preference.

## Dynamic Type (Large — default)

The standard scale at `LiqDynamicTypeScale.large` (1.0×) — the
system default that matches what users see out of the box.
