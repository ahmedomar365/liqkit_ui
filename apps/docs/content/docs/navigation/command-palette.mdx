`LiqCommandPalette` is a modal floating panel with a search field on
top and a filtered list of commands beneath. Each command can carry an
icon, a keyboard shortcut hint, and free-text keywords to broaden
fuzzy matches. Show it imperatively with `LiqCommandPalette.show(...)`
or embed the widget directly. Up/Down arrows move the active row,
Enter triggers it, Escape dismisses.

## Default

A flat list of commands with shortcut pills.

## Sections

Set the `section` field on each `LiqCommand` to group related commands
under uppercase headers — the palette renders one header per group in
order of first appearance.
