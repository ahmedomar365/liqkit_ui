`LiqBreadcrumb` is the iOS 26 navigation trail used to surface where a
view sits in a page hierarchy. Each `LiqBreadcrumbItem` renders as a
tappable link in iOS system blue when its `onPressed` is non-null. The
final crumb is rendered in semibold iOS primary-label color and is
never a link — it represents the current page.

## Default

The default separator is a forward slash in iOS tertiary-label grey.
Tap any non-final crumb to fire its `onPressed` callback.
