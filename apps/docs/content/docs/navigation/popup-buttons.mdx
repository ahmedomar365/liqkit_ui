The popup-button family covers three patterns: a value-selecting popup
(`LiqDropdownButton`), an action-only pull-down (`LiqPullDownButton`),
and a split button with a primary action plus a chevron menu
(`LiqSplitButton`). Every variant below is the same widget the
showcase app uses — sourced from `package:liqkit_ui/examples.dart`.
