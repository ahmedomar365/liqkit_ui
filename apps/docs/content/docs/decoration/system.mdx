Low-level system chrome components used inside Quick Actions rows and device
mockups. All three are purely decorative — they do not carry their own state
management.

## Home Indicator

`LiqHomeIndicator` renders the 144×5 black pill inside a device-tinted 11pt
rounded slot. Use `layout` to switch between iPhone portrait/landscape and
iPad portrait/landscape sizes.

## Action Pill

`LiqSystemActionPill` renders a 42pt gradient pill used in Home Screen Quick
Action rows. Supports `regular` and `destructive` styles and `light`/`dark`
brightness variants.

## Toggle Dot

`LiqSystemToggleDot` renders a 38×38 circle that fills with system blue when
