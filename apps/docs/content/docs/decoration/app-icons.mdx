`LiqAppIcon` renders a 66pt squircle tile (14pt corner radius) with an
optional glyph centered inside. Use `LiqAppIconBadge` to overlay a red
notification count at the top-right, and the `label` parameter to show a
caption below the tile.

| Parameter | Description |
|-----------|-------------|
| `size` | Tile dimension in logical pixels (default 66) |
| `color` | Solid background color |
| `gradient` | Optional vertical gradient (overrides `color`) |
| `glyph` | Widget centered inside the tile |
| `badge` | Optional `LiqAppIconBadge` widget |
| `label` | Caption string shown beneath the tile |
